# 🎨 Dream Canvas - 灵魂画手拯救计划 (独立重构版)

这是一个结合了 Web 前端交互与阿里百炼 (通义万相) “涂鸦作画” 大模型的全栈演示项目。旨在将简易线条转化为极其惊艳、风格化的数字插画。

本项目现已在 `picture` 文件夹下被**完美重现与独立封装**，消除了之前在 Windows 路径和 SDK 接口传参上的所有已知问题，可直接本地化部署展示。

---

## ✨ 核心特性

- **🎨 交互式魔法画板**：支持鼠标和触屏，具备自定义色盘、橡皮擦、粗细调节和一键清空功能。画板初始化自动补全纯白底色以增强模型识别率。
- **👾 阿里百炼旗舰级模型对接**：使用功能更强大、输出画质更惊艳的 **`wanx-v1` (通义万相旗舰图生图)** 模型。
- **🔥 独家无错上传专利**：后端集成阿里 SDK 隐藏的 `OssUtils` 工具类。在提交生成前，会将临时图片静默上传到百炼官方 OSS 中转，生成标准的 `oss://` 内部协议地址传递，**彻底、完美地从底层解决了阿里云 SDK 对 Windows 路径的反斜杠解析 Bug (`url error`)！**
- **🌃 星空梦幻 (Cosmic Dream) 主题**：现代化的玻璃拟物设计 (Glassmorphism)、粒子点缀与极具科技魔幻气息的“魔法施法”加载动效。
- **⚡ 零侵入隔离**：独立于其他项目目录，拥有完整的依赖记录与静态文件结构。

## 🚀 快速启动流程

### 1. 安装环境依赖
打开终端 (PowerShell/CMD)，切换到 `picture` 文件夹路径，安装独立的 Python 依赖库：
```bash
cd d:\Projects\aicourse\picture
pip install -r requirements.txt
```

### 2. 配置 API Key
您有两种方式设置阿里云百炼 API Key：
- **方式 A (推荐)**：直接在您的系统环境变量中配置 `DASHSCOPE_API_KEY`。后端会自动检测此变量。
- **方式 B (本地配置文件)**：修改本目录下的 `.env` 文件，将其中的 `DASHSCOPE_API_KEY=在这里填入你的_阿里百炼_API_Key` 后半段替换为您的真实 Key。

### 3. 启动本地服务
确保依赖安装完毕后，在该目录下执行以下命令以在本地 `8000` 端口拉起服务：
```bash
python main.py
```
或者使用 uvicorn 拉起并自带热更新：
```bash
uvicorn main:app --reload --port 8000
```

### 4. 浏览器访问
一切就绪后，在浏览器内输入并打开：
🔗 **[http://127.0.0.1:8000](http://127.0.0.1:8000)**
